# NeKo VPN 🐾

Ứng dụng VPN dành cho Android được xây dựng trên nền tảng Xray-core, hỗ trợ đầy đủ các giao thức kết nối bảo mật và tối ưu hóa cho mạng di động.

## ✨ Tính năng nổi bật
- **Giao diện NeKo VPN:** Logo và nhận diện thương hiệu riêng biệt, thân thiện.
- **Tối ưu mạng 4G/5G:** Hỗ trợ đầy đủ các cấu hình VLESS, VMess, Trojan, Shadowsocks (hỗ trợ cả VLESS/ws qua cổng 80).
- **Tự động đóng gói APK:** Tích hợp quy trình CI/CD tự động ký và build APK trực tiếp qua GitHub Actions.
